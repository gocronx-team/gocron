# 安全加固与兼容升级

反向代理部署建议在调度端设置 `GOCRON_PUBLIC_URL=https://scheduler.example`，
固定安装命令与脚本中的服务来源，不再依赖请求 Host。仅接受 HTTP(S) origin，
不允许凭据、路径、查询参数和片段；无效配置会拒绝生成安装命令及脚本。
仅在确实需要根据请求主机自动发现地址时保持未设置。

快速安装脚本支持从安装者环境读取可选的 `GOCRON_NODE_SHA256`，在解压前校验
下载包。请通过独立可信来源取得摘要，下载并审阅脚本后执行
`GOCRON_NODE_SHA256=<可信的64位十六进制摘要> bash install.sh`。
未设置时保留旧安装流程，但会明确警告没有固定包摘要。摘要校验不认证脚本本身，
脚本仍须经可信 HTTPS 获取；不要把同一不可信服务器提供的摘要当成独立信任依据。

旧配置仍可使用，但默认未鉴权节点和明文 RPC **并不安全**。

## 节点通信

- 不要将 5921 端口暴露公网；防火墙仅允许调度器访问。
- 推荐调度器和节点同时配置双向 TLS，使用专用 CA 和独立证书。
- 节点可添加 `-require-secure -enable-tls -ca-file ... -cert-file ... -key-file ...`。
  严格模式拒绝未启用 TLS 的启动；证书仍须通过既有验证。
- `rpc_token` 与 `GOCRON_NODE_TOKEN` 提供鉴权，不提供加密。
- 快速安装脚本不自动配置双向 TLS，请在开放节点网络前检查服务配置。
  不要将共享令牌或证书私钥写入安装 URL 或公开脚本；请通过独立可信通道配置凭据。
  当前未实现自动注册及证书轮换。
- 使用可信 HTTPS 下载，并用独立可信的摘要或签名验证安装包。同通道下载的摘要不能替代可信签名。

先准备证书及调度器配置，再逐节点启用 TLS；保留配置备份以供回滚。
鉴权或 TLS 失败后不要自动退回明文。

## 出站 HTTP

调度器启动时设置 `GOCRON_HTTP_PUBLIC_ONLY=1`，共享 HTTP 任务、Webhook 和
Slack 客户端将拒绝私网、回环、链路本地、多播及运营商 NAT 地址。
在建立连接时解析并检查地址，直接连接检查过的数值 IP，重定向的新连接也执行检查。
变更该环境变量需重启进程。

需要正常访问内网任务的部署应保持默认行为，并通过编辑权限和出站防火墙/代理白名单约束访问，
尤其应阻止云元数据服务。此选项不是完整网络沙箱，其他客户端（包括 AI 提供商）、
路由/NAT 和应用代理仍需单独限制，不应据此宣称 SSRF 风险完全解决。

## 单次 HTTP 参数

旧 `GET /api/task/run/:id` 保持不变；新接口 `POST /api/task/run/:id`
接受 `{"http_body":"{\"date\":\"2026-10-01\"}"}`，仅适用于 HTTP POST 任务。
JSON 请求体最多 65535 字节，只覆盖本次执行副本，不保存任务配置，不改变定时、并发和重试规则。
审计不记录请求体。前端查询 `/api/task/run-capabilities`，旧后端未声明能力时隐藏新入口。
新请求失败后不得自动回退旧 GET，以免重复执行。

## 最小 Prometheus 接口

`GET /api/system/metrics` 使用既有管理员鉴权，返回 Prometheus 文本。
采集器通过 `http_headers` 传递有效管理员 `Auth-Token`，或使用负责续期的安全本地代理，
不要暴露无鉴权代理。目前仅包含版本、进程运行时长和 goroutine 数量，无数据库扫描、
任务级标签、历史执行计数或 HA 汇总；多个副本分别采集。
